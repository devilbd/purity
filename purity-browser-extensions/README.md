# Purity Browser Extensions

Official developer tooling and browser inspection extensions for the **[Purity Framework](https://github.com/devilbd/purity)**.

---

## Available Extensions

- **[Chrome Extension (DevTools & Manifest V3)](chrome/README.md)**: Full Developer Tools panel extension for Google Chrome, Microsoft Edge, Brave, Arc, Vivaldi, Opera, and other Chromium browsers. Inspects components, services, dependency injection, signals, effects, and performance profiling.
- **[Mozilla Firefox Extension (DevTools & WebExtensions Manifest V3)](mozilla/README.md)**: Full Developer Tools panel extension (1:1 feature parity) for Mozilla Firefox, Firefox Developer Edition, Zen Browser, LibreWolf, Waterfox, Floorp, and other Gecko browsers. Inspects components, services, dependency injection, signals, effects, and performance profiling.

For download and installation instructions, see:
- **[Chrome Extension README](chrome/README.md)**
- **[Mozilla Firefox Extension README](mozilla/README.md)**
