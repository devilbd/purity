# Purity Browser Extensions

Official developer tooling and browser inspection extensions for the **[Purity Framework](https://github.com/devilbd/purity)**.

---

## Available Extensions

- **[Chrome Extension (DevTools & Manifest V3)](chrome/README.md)**: Full Developer Tools panel extension for Google Chrome, Microsoft Edge, Brave, Arc, and other Chromium browsers. Inspects components, services, dependency injection, signals, effects, and performance profiling.

For download and installation instructions, see the **[Chrome Extension README](chrome/README.md)**.
