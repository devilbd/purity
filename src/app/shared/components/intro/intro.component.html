About Purity Framework

A lightweight, native TypeScript frontend framework powered by fine-grained signals, native Web Components, Dependency Injection, and Composable Behaviors.

GitHub

1. 🔄 Fine-Grained Reactive Signals & Effects (core.ts)

Synchronous reactivity primitives with automated dependency tracking and sub-microsecond updates:

import { signal, effect } from './framework/core';

// Create a reactive signal container
const count = signal(0);

// Read value
console.log(count()); // 0

// Mutate via .set() or .update()
count.set(5);
count.update(n => n + 1);

// Effects track signal reads automatically and re-run on changes
effect(() => {
    console.log(`Current counter: ${count()}`);
});

2. 🧩 Native Web Components (component.ts)

Plain TypeScript classes transformed into native Custom Elements with synchronous template inlining and lifecycle management:

import { Component, signal } from './framework/core';
import './custom.component.scss';

@Component({
    selector: 'custom-component',
    templateUrl: './custom.component.html',
})
export class CustomComponent {
    customProperty = signal<string | null>(null);

    protected onInit() {
        // Runs after template DOM nodes are mounted
    }

    onInput(element: HTMLInputElement) {
        this.customProperty.set(element.value);
    }
}

3. 📄 Handlebars Template Interpolation ({{ expression }})

Embed reactive signals directly into HTML templates using handlebars syntax. Expressions are compiled and cached in expressionCache, automatically re-rendering whenever dependent signals change:

<!-- 1. HTML Template: Declarative Signal Rendering -->
<div class="window">
    <!-- Reactive text content bound to signals -->
    <h3>Welcome, {{currentUser()}}!</h3>
    <p>Count: {{count()}} (Doubled: {{count() * 2}})</p>

    <!-- Reactive attribute and CSS class interpolation -->
    <div class="badge {{statusClass()}}">
        Status: {{statusText}}
    </div>

    <!-- Dynamic input value binding -->
    <input type="text" value="{{currentUser()}}" class="input-primary" />
</div>

<!-- 2. Component Class: Signal Definitions -->
@Component({ selector: 'user-card', templateUrl: './user-card.html' })
export class UserCardComponent {
    currentUser = signal('Alice');
    count = signal(5);
    statusClass = signal('is-online');

    get statusText() {
        return this.currentUser() ? 'Active' : 'Offline';
    }
}

4. 💉 Dependency Injection (di.ts)

Singleton service registration with @Injectable and fast token resolution via inject():

import { Injectable, signal, inject, Component } from './framework/core';

@Injectable('DataService')
export class DataService {
    currentUser = signal<string | null>(null);

    login(name: string) {
        this.currentUser.set(name);
    }
}

@Component({ selector: 'app-component' })
export class AppComponent {
    private dataService = inject(DataService);
}

5. 📋 Decoupled Form Validation (validator.ts)

Decorators decoupling validation logic, tracking field states, applying CSS classes, and toggling submit button states:

import { Validator, BaseValidator } from './framework/core';

@Validator({
    form: '.forms-validation-form',
    fields: {
        input1: '#input1',
        input2: '#input2',
    },
    validClass: 'is-valid',
    invalidClass: 'is-invalid',
})
export class FormsValidationValidator extends BaseValidator {
    validateInput1(value: string): boolean {
        return value.trim().length >= 3;
    }

    validateInput2(value: string): boolean {
        return value.trim().length >= 5;
    }
}

6. 🏷️ Custom Directives (directive.ts)

Attribute-level reactivity and DOM augmentation with @Directive and BaseDirective:

import { Directive, BaseDirective } from './framework/core';

@Directive('highlight')
export class HighlightDirective extends BaseDirective {
    onInit() {
        this.element.classList.add('p-highlight');
    }

    onChanges(newValue: any) {
        this.element.classList.toggle('p-highlight--active', !!newValue);
    }
}

7. 🎯 Composable Behaviors: Drag & Droppable (behaviors/)

Pointer-based drag interactions with GPU acceleration (translate3d), boundary constraints, and center snapping:

import { drag } from './shared/behaviors/draggable/draggable';
import { droppable } from './shared/behaviors/droppable/droppable';

// Register droppable drop zone
const dropZone = droppable({
    selector: '#droppable-container',
    accepts: '#component1',
    hoverClass: 'droppable-hover',
    onDrop: (el) => el.remove(),
});

// Attach drag behavior
const dragHandle = drag({
    selector: '#component1',
    constrainTo: 'body',
    snapTo: '#droppable-container',
    handle: '.drag-handle',
});
